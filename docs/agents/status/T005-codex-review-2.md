后果：用户选择真实目录后，`需求与排期` 页面仍会显示：

- 高校食堂线上订餐支持多门店分账

- 营养餐结算台账导出

要求：

- `TasksView` 使用传入的真实 `tasks` 数据；无真实需求时显示明确空状态。
- 浏览器预览模式才允许显示演示需求。

### 2. 文档页仍显示写死的演示 HTML 原型

`src/ui/DocumentsView.tsx` 中 `htmlPrototypes` 仍硬编码：

- 北城医大·食堂订餐首页原型
- 华东园区·收银升级交互原型

后果：即使选择了真实目录，文档页仍会出现与所选目录无关的演示内容。

要求：

- 文档页展示所选目录中的真实文件；无文件时显示明确空状态。
- HTML 原型应从所选目录中的 `.html` 文件生成，或在本任务先隐藏为“未导入”空状态，不能继续硬编码示例原型。

- 文档：文件为空时只显示空白网格，同时仍显示硬编码原型。

要求：
