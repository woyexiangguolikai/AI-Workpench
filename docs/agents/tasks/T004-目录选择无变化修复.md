## 目标

修复桌面版点击“选择目录”后界面没有任何变化的缺陷。用户反馈在应用中选择目录后，页面没有同步显示所选择的目录或扫描结果。

## 复现步骤

1. 使用 `npm run desktop` 或最新打包 exe 启动应用。
2. 点击顶部栏“选择目录”，或进入“设置”点击“重新选择目录”。
3. 在弹出的原生目录选择框中选择一个已存在目录。
4. 确认：
   - 页面顶部“当前资料目录”是否立即更新为新目录；
   - 是否出现文件扫描汇总；
   - 是否出现任何 Toast 或持久化错误提示。

用户反馈当前结果：选择目录后页面没有任何变化。

## 需要核查的原因

- 打包后的 exe 中 `preload.cjs` 是否正常加载，`window.desktop` 是否存在。
- `dialog:selectDirectory` 是否正常打开原生目录选择框并返回路径。
- 渲染进程拿到路径后是否执行 `setSelectedFolder`，顶部目录文本是否更新。
- `directory.scan` 失败时是否被静默吞掉，导致用户只看到目录路径变化、没有扫描结果。
- 路径含中文、空格时是否触发异常。
- 浏览器预览模式与 Electron 模式的目录选择行为是否被混淆。
